NEUROTIC - CUSTOMER CANDIDATE

UNINSTALL
Every public package includes NeuRotic-Uninstall.cmd. Run it, select the same game
executable used for installation, review the detected proxy and settings choice,
then confirm. Setup also places "Uninstall NeuRotic.cmd" directly in the game folder;
that copy already knows which game it belongs to and does not ask you to browse again.

The uninstaller reads the verified installation record first. It automatically knows
whether NeuRotic was installed as dxgi.dll, winmm.dll or another supported proxy and
walks stacked updates back to the original pre-NeuRotic state. If no record can be
proved, it enters a clearly labeled manual recovery mode and asks which proxy you used.
It never deletes an arbitrary dxgi.dll merely because the filename looks familiar.

The recommended option saves current settings under NeuRotic\UserData while returning
the active game files to their exact pre-install state. Setup automatically reuses
those settings on reinstall. Remove Settings discards the saved NeuRotic settings.
Full Cleanup additionally removes installer history and backups. The user-supplied
nvngx_dlssnr.dll model is always preserved unless its separate advanced removal
option is explicitly requested and confirmed.

INSTALL
1. Extract the complete ZIP to a folder outside the game folder.
2. Close the game and double-click NeuRotic-Setup.cmd.
3. Select the game's actual executable, rather than its launcher.
4. Choose the proxy filename your game should load. DirectX games normally use
   dxgi.dll; Vulkan games normally use winmm.dll. Setup also offers version.dll,
   dbghelp.dll, d3d12.dll, wininet.dll, winhttp.dll, OptiScaler.asi and OptiScaler.dll.
5. If the selected filename is free, Setup installs immediately. If it already
   exists, choose whether to back it up and replace it, choose another name, or
   cancel. For dxgi.dll only, you can instead keep it as ReShade64.dll and enable
   ReShade compatibility. Setup never guesses who owns an existing file.
6. Wait for "full installation verified", then launch your game.

After the first managed installation, Setup remembers the selected proxy, release
and installation time. Running Setup again offers Update/Repair, Change Proxy or
Uninstall. Updates reuse the recorded proxy automatically. A proxy change restores
or removes the old managed loader and installs the new one as one rollback-safe
transaction. ReShade-linked dxgi.dll changes deliberately use uninstall-then-install
so the original ReShade placement is restored before selecting another proxy.

When dxgi.dll already exists, Setup displays these choices in this order:
1. Replace the file (Backup of original will be created)
2. Rename to ReShade64.dll - Choose this if you want to use NeuRotic and ReShade
3. Choose a different Filename
4. Cancel

You never need to type INSTALL. If you keep an existing dxgi.dll as ReShade64.dll,
Setup also enables LoadReshade in OptiScaler.ini without changing its encoding.
If ReShade64.dll already exists, Setup stops instead of overwriting it.

Press Insert to open NeuRotic, unless you have saved another shortcut.
Enable Neural Rendering there. Start with one pass; try two for Multi-Pass.
Model Resolution, Model Strength and Detail Strength in Multi-Pass adjust all
selected child passes together. Release a slider to apply. Pass 1 stays independent.

SETTINGS AND MODEL
Existing settings and your nvngx_dlssnr.dll model are preserved during installation,
except that choosing the ReShade option sets LoadReshade to true.
New installations start with NR, Multi-Pass and file logging OFF.
The default DLSS Performance and Ultra Performance presets are L.

The NVIDIA NR model is not included. Supply your own nvngx_dlssnr.dll beside the
game executable before enabling NR. The included nvngx.dll_dlssnr.dll is a
different file: it is the forwarder. Both are needed for NR.

RESTORE YOUR PREVIOUS INSTALLATION
Use Uninstall NeuRotic.cmd in the game folder for the normal public uninstall flow.
Setup also retains its low-level Restore.cmd in each verified recovery folder for
support and emergency rollback. The public uninstaller follows those records in the
correct order automatically; users no longer need to restore several versions by hand.

NEED HELP?
Keep the extracted package together. The support folder contains internal setup
files, build information and a testing guide; you only need to launch Setup.
If access is denied, run NeuRotic-Setup.cmd as administrator.
If the selected filename exists, choose its disposition yourself in Setup.
For troubleshooting, enable file logging at Info in Diagnostics, restart, reproduce
the problem and retain OptiScaler.log. Switch logging off again afterwards.

This candidate is for testing before release. The preceding version passed the
author's smoke tests in MHWilds, Dragon's Dogma 2 and Crimson Desert; the shared
strength controls in this version need your confirmation in game. Known DD2
first-menu/shop performance drops remain under investigation.

Use only in games that permit modifications; avoid protected online sessions.
These files are unsigned. No model downloads are performed by Setup.

Linux/Proton runtime compatibility has been reported by users, but this package's
Setup and Restore launchers are for Windows. No Linux installer is included here.
