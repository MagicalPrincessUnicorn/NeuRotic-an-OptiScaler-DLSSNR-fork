NEUROTIC ALPHA 0.9.6 - MENU AND EXPERIMENTAL CONTROLS REVIEW

Keep experimental. This matched folder is for review and separately authorized
runtime testing. It is not a release, stable promotion or selected public candidate.
Source identity and binary hashes are in support\PACKAGE-MANIFEST.json and
support\BUILD-MANIFEST.json. Keep this complete folder outside the game folder.
No archive extraction or Downloads location is required.

WHAT CHANGED
Analyze All Routes tests each compatible route in sequence. Test This Route on an
individual card tests only that route. Both use the selected resolution preference
and restore the original settings. Unsupported routes are skipped with a reason;
unknown native cadence, stalls and incomplete samples cannot produce a successful
measurement. Changing routes may still interrupt rendering, so the reported hitch
needs exact-binary tests. Frame Generation settings do not prove actual generated-
frame presentations.

Resolution choices are Always Full Output, Match Game Render (recommended), and
Manual (25-200%). Incompatible placement choices show a reason. Existing explicit
profiles are retained. Very low Manual resolution can lose detail and the NR effect.
Neural Rendering sections start collapsed and their headings show ON, OFF or BLOCKED
status. OptiClip is visible by default, speaks above its avatar and can be hidden in
General.

General has separate gameplay-input controls while the menu is open. Defaults:
mouse blocked, keyboard allowed, controller allowed. Checkbox edits remain pending
until Save Input Settings or the global Save Settings succeeds; closing the menu
discards unsaved edits. This prevents a mouse-policy edit from applying while the
user still needs the menu.
Allowed keyboard/controller devices do not navigate the menu. Allowed mouse clicks
can affect both menu and game. Standard XInput/DirectInput are covered; custom
DirectInput, GameInput, Windows.Gaming.Input and raw HID controllers may bypass it.
Held-input/focus behavior still needs exact-binary game testing.

The Neural Rendering tab has an Unlock Experimental Mode master switch below
Multipass, with Multipass, HDR, Frame Generation and camera-cut reset options.
Activation requires a warning confirmation.
Edits apply only after Save Experimental Settings or the global Save Settings.
An unclean prior session automatically disables the master and every override on
the next launch. Hard checks that protect against known GPU corruption remain in
force even when an override is saved.

New comparison captures contain PNG images only, with versioned provenance embedded
inside each image. Existing images and old sidecars are preserved. No brightness
gain or correction has been added.

RUNTIME LIMITS
Native Temporal, Present Image Only and Present Enhanced expose screenshot
comparisons. Native display conversion has a known defect: brightness may differ.
No brightness correction is applied. Performance comparisons use temporary DLSS
evaluations with fresh history; they do not reproduce accumulated live history.
Present Enhanced image quality and combined FG/RR/Multipass behavior still require
runtime testing. Unsupported resource or provider contracts are refused.

FUTURE AUTHORIZED INSTALLATION
Close the game. Run NeuRotic-Setup.cmd and select the actual game executable and
proxy filename. Read the detected-file decision before proceeding: selecting a
free filename installs immediately. Existing settings are preserved; selecting
ReShade compatibility explicitly enables its setting. Fresh installations use
the revised default integration INI recorded in the build manifest.

The private nvngx_dlssnr.dll model is not included. Preserve or supply your own
model before enabling NR. The included nvngx.dll_dlssnr.dll is the forwarder,
not the model. Dependency files and redistribution licenses are included.

UNINSTALL AND RECOVERY
Run NeuRotic-Uninstall.cmd for the same game, or the installed
"Uninstall NeuRotic.cmd". Recommended Keep Settings restores the original game
files and retains NeuRotic settings for reinstall. The private model is preserved.
For an interrupted uninstall, run the uninstaller again and choose recovery first.
Keep its recovery folders until recovery completes. Setup also retains Restore.cmd
inside each verified backup folder for exact rollback.

The installer verifies ownership and restore history, refuses linked paths,
supports repeated proxy changes and recovers interrupted operations. It never
infers ownership from a DLL filename alone. This package was prepared without
deploying to a real game. See the accompanying review report for fixture evidence
and the runtime acceptance matrix before planning a game test.
