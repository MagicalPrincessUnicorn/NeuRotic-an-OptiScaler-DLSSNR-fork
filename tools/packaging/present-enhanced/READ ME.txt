WHEN YOU CHOOSE TO TEST
Close the game and run NeuRotic-Setup.cmd from this folder. The exact candidate
installer is retained: select the actual game executable and a supported proxy
filename. A free name installs immediately. Occupied names offer backed-up
replacement, another name or cancel. DXGI also offers the explicit ReShade rename.
Existing INI/model are preserved except the explicit ReShade choice sets
LoadReshade=true. Fresh installs start with NR OFF, Present Enhanced selected,
Follow Native Render Resolution selected, and Logging > To File OFF. Upgrades
preserve saved route and logging choices; existing logging is not switched off.
The backup folder's Restore.cmd restores the original installation.

PRESENT ENHANCED ACCEPTANCE
Use DX12 SDR, frame generation OFF, NR Multipass OFF, RR OFF. Supply your existing
private NVIDIA nvngx_dlssnr.dll; it is not distributed in this package.
Enable Neural Rendering is the first control. Choose Native Temporal, Present
Image Only, or Present Enhanced. Present routes remember their own NR resolution:
Follow Native Render Resolution, Always Follow Output Resolution, or Custom Scale.
Custom Scale reveals 100%, 77%, 67%, 58%, 50%, and 33%. Quality/Performance and
model-resolution controls belong to Native Temporal and retain their behavior.
Extra passes require Enable NR Multipass on a compatible route. Saved pass profiles
remain editable before activation. Present Enhanced requires NR Multipass OFF.

First test Always Follow Output Resolution (100%). Then test Follow Native Render
Resolution, Custom Scale 67%, and Custom Scale 50%. Follow Native requires fresh matched game
render-subrect metadata and aligns private work down to multiples of eight pixels.
Actual NR and output dimensions are shown. No DLSS preset-name inference is used.
Unavailable dimensions mean there is no current result. Open Advanced Data /
Diagnostics for capture/match/evaluation counts, errors, history and timings.
Opening Diagnostics does not enable file logging or change rendering.

For EACH setting compare Image Only / Enhanced / Image Only (A/B/A) in the same
scene with the same model and tuning. Let history settle after each switch.
Enhanced must show sustained increasing capture/match/evaluation counts, active
Present Enhanced placement, and successful output. An unchanged fallback is not
successful Enhanced NR. Record any visible refusal and the actual dimensions.
Compare faces, cloth, highlights, motion, disocclusions and game HUD. Test menus,
loading, camera cuts, route changes, NR toggles, dynamic resolution and resizing.
Record longer-session results and reset/rebuild recovery, not just a brief launch.

Scene guides do not describe HUD pixels. The final game HUD remains included in
the processed Present image; unchanged HUD pixels are not guaranteed.
DX11, Vulkan, HDR, RR, frame generation and NR Multipass are not supported for
Enhanced. Partial output subrects, unsupported guide formats, multiple Native
evaluations, stale guides, or different producer/Present queues refuse processing.
