NEUROTIC

Download the complete installer bundle from the official GitHub release. Extract the complete ZIP outside the game folder and open NeuRotic.exe.

Select or add a game, close it, and use Installation. Install keeps saved settings; Fresh Install resets them to package defaults. Use Uninstall to remove a managed installation. Manual setup and uninstall entry points are included in the bundle.

A compatible neural-rendering model is supplied separately. The forwarder is not the model. For troubleshooting, select the game in Installation Library and export a diagnostic ZIP from Diagnostics.
